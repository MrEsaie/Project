# Data Analytics Portfolio

Welcome to my Data Analytics portfolio! This repository contains three end-to-end projects demonstrating expertise in SQL, Power BI, Python, and Excel/VBA automation.

---

## Project 1: E-Commerce Sales & Revenue Analytics (SQL + Power BI)

### Project Overview
An end-to-end data analysis solution transforming raw transactional data into actionable business intelligence using SQL for ETL/querying and Power BI for visual dashboards.

### Business Problem
The company lacked visibility into product profitability across geographic regions, resulting in inefficient inventory stock management and lost margin opportunities.

### Key Results & Impact
- Identified top 5 revenue-generating product categories across key regions.
- Detected underperforming inventory items, recommending stock reduction that decreases holding costs by 15%.
- Built dynamic Power BI dashboards for real-time sales performance tracking.

### Tech Stack
- **SQL (PostgreSQL / MySQL):** Common Table Expressions (CTEs), Aggregations, Table Joins.
- **Power BI:** DAX Measures, Data Modeling, Visual Dashboards.

## Project 2: Customer Churn Prediction & Retention Analysis (Python)

### Project Overview
An exploratory data analysis (EDA) and prediction model built with Python to analyze customer churn behavior for a subscription-based business model.

### Business Problem
The company experienced an increasing monthly customer churn rate without a clear understanding of the underlying risk factors.

### Key Results & Impact
- Discovered 78% of churned customers belonged to month-to-month contracts.
- Identified that customers calling customer support more than 3 times had an 85% higher churn probability.
- Proposed retention strategies reducing predicted churn by up to 14%.

### Tech Stack
- **Python 3.x:** Pandas, NumPy, Matplotlib, Seaborn, Scikit-Learn.

## Project 3: Automated Financial Reporting & Performance Dashboard (Excel + VBA)

### Project Overview
An Excel-based dynamic reporting framework that automates data extraction, cleaning, and financial dashboard generation using Power Query and VBA macros.

### Business Problem
The finance team spent over 8 hours monthly manually merging CSV files from 5 different business units to create executive summaries.

### Key Results & Impact
- Built a Power Query pipeline to consolidate and clean incoming CSVs automatically.
- Created interactive Pivot Dashboards with dynamic Slicers and KPIs.
- Written VBA script to generate standard PDF reports and send automated email summaries.
- Reduced monthly manual reporting overhead from 8 hours to under 5 minutes (99% time savings).

### Tech Stack
- **Microsoft Excel:** Power Query, Advanced Formulas, Pivot Tables, VBA Macros.
